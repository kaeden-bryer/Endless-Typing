# ⌨️Endless Typing

Endless Typing is an accountability app that seeks to break down writer's block by enforcing a negative incentive. The concept behind Endless Typing is that writing **is** brainstorming, and that writing is the process the writer needs to understand what it is they're writing about. Yet, if you're like me, you'll stare at a blank page contemplating for hours what the first word should be. Endless typing asks the user to input a length of time they would like to type, and then forces them to keep typing for the entirety of that time, even if it isn't perfect. If the user stops typing for 5 or more seconds, the words will disappear off the page forever.

Try Endless Typing Here: https://kaeden-bryer.github.io/Endless-Typing/homepage.html
