# ⌨️Endless Typing

Endless Typing is an accountability app that breaks down writer's block by enforcing a negative incentive. 

If you're like me, you'll stare at a blank page contemplating for hours what the first word should be. 

The concept behind Endless Typing is that writing **is** brainstorming. So someone who doesn't know what to write should write, but won't.

Endless Typing asks the user how long they would like to write, and then forces them to keep writing for the entirety of that time. If the user stops writing for 5 seconds, the words will disappear off the page forever.

Thus, Endless Typing forces the user to power through a first draft, kickstarting the writing process and subverting writer's block.
